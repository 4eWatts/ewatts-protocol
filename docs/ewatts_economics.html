How the supply, cost and incentive curves evolve

Interactive model of the eWatts emission formula. No drift, no inflation target, no oracle. Adjust the adoption scenario to see how the bootstrap phase transitions into mature operation under different network growth trajectories.

eWatts is a neutral settlement layer anchored to the physical cost of memory-bound computation. Its supply is not capped, but it is also not arbitrary — each eWatt corresponds to real energy spent by the network. The charts below illustrate how this works in practice across adoption scenarios.

How to read this

The protocol has two phases that flow continuously into each other. During bootstrap, emission per block is multiplied by a factor that decays from 100,000× to 1× as cumulative supply approaches the threshold. This creates strong incentive for early miners while ensuring the multiplier resolves naturally over time.

At formal maturity (supply reaches 10B), the multiplier is 1, and emission becomes proportional only to active network size. Each block emits enough eWatts to absorb the network's real energy consumption at the calibrated cost — no more, no less.

Post-maturity, supply continues to grow ad infinitum. There is no cap. But growth is not arbitrary either: it tracks real network expansion. If the network grows, supply grows proportionally. If the network stabilizes, supply expansion slows naturally.

What is not in the formula

  • No inflation target. The protocol does not codify an arbitrary inflation rate.
  • No drift mechanism. P_target does not decay over time. The anchor is stable.
  • No oracles. No external price feeds, no off-chain dependencies, no governance committees.
  • No founder allocation. No pre-mine, no admin keys, no privileged minting.
  • No supply cap. Hard caps create scarcity pressure that conflicts with settlement function.

What remains is a single emission curve, parameterized by four numbers: M_max, S_threshold, N_calibration, and P_target. Everything else emerges from these and from the physical constraints of memory-bound mining.

Open questions, acknowledged

The model above is honest about its limits. Two tensions remain:

Long-term security budget. Once the network stabilizes, per-block rewards become small relative to total supply. Miners will increasingly depend on transaction fees. This is the same tension Bitcoin faces (block reward already at 0.83% annually and falling). No definitive solution exists yet; community evaluation when the problem arises is more honest than codifying an arbitrary parameter now.

Adoption is uncertain. Every forward-looking value in this dashboard depends on network growth that has not happened. The protocol exists. The economic model exists. Adoption is a bet, not a derivation.

Model assumptions. Block time 600 seconds. Node power 75 W. Reference electricity price $0.165/kWh (US EIA residential average 2024–2025). Bootstrap multiplier M(S) = max(1, 100,000 × exp(−ln(100,000) × S / 10,000,000,000)). Mature emission = N × $0.002063 / $1.00. Maturity boundary at supply ≥ 10B eWatts. Per-miner reward assumes equal commitment across active miners. Adoption curves modeled as logistic functions to target N over specified period. Reference inflation values: Bitcoin 0.83% post-2024 halving (industry sources); gold 1.7% (World Gold Council, 25-year average); USD M2 ~6.5% (Federal Reserve long-run average). All forward-looking metrics depend on network growth that has not yet occurred — these are illustrations of the model, not predictions of outcomes.
