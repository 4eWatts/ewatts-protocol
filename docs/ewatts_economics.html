Economic Model — v0.5 · Protocol 0x0005 · AOPS

Free entry as equilibrium

Each node is a continuous bid in an implicit auction. The block reward is fixed at 100 eWatts. Under free entry, the network finds its own size: the margin goes to zero and bandwidth becomes endogenous. The Value Reference converges to P / pelec — hardware efficiency drops out of the equation.

The key result. A 5% efficiency improvement does not weaken the energy anchor. It allows 5% more nodes to enter at the same total energy. The drift is absorbed by network size, not by the Value Reference. The previous simulations showing 5-7%/year drift modeled the scenario where entry is frozen — the only scenario where the market mechanism is disabled by construction.

Equilibrium nodes vs market price

At any price P, free entry drives the node count to N = 8,000 x P / p_elec (for W = 75W). Doubling P doubles N.

Value Reference = P / pelec

The VR converges to market price divided by electricity cost. Hardware efficiency does not appear. The anchor is an economic equilibrium, not a physical constant.

Network energy over 20 years

As efficiency improves 5%/year, node power drops, margins open, new nodes enter. Network energy stays flat. The drift is absorbed by N.

Tokens per kWh — bootstrap to equilibrium

During bootstrap, N is small and tokens per kWh starts high. As N grows toward equilibrium, eWatt/kWh converges to p_elec / P. The convergence speed depends on how fast N grows.

The derivation

Each node running eWatts consumes W watts. Over one 600-second block, the electricity cost is:

c = W x 600 x p_elec / 3,600,000   ($/block/node)

For a 75W DDR5 node at $0.10/kWh: c = $0.00125/block/node.

With N identical nodes and a block reward of 100 eWatts, free entry competition drives the margin to zero:

N x c = 100 x P
N = 8,000 x P / p_elec   (for W = 75W)

Network energy per block:

E = N x W x 600 / 3,600,000 = 100 x P / p_elec

The Value Reference at equilibrium is simply:

VR = E / 100 = P / p_elec

W cancels completely. Hardware efficiency does not appear in the equilibrium VR. Energy improvements are absorbed by N, not by the anchor.

The real risk: bootstrap entry lag

The equilibrium assumes instant entry and exit. During the bootstrap phase with few nodes and low liquidity, the response to a margin signal has delay. During that delay, efficiency drift affects real returns. This risk is real, measurable, and temporary. It exists on every young PoW network, and eWatts minimizes it relative to others because no ASIC fabrication lag exists.

Why a burn auction is unnecessary

An explicit bidding mechanism (burning eWatt for reward weight) would also stabilize the system, but compare where the margin goes: free entry absorbs it via new nodes (more distribution, wider decentralization), while a burn auction absorbs it via supply destruction (same incumbents, injects a PoS-like barrier). For a protocol built on accessibility and neutrality, free entry is strictly superior. The auction you asked about already exists.

Comparison to Bitcoin

Bitcoin has the same fundamental identity (production cost ≈ revenue, per Cambridge CCAF). The difference is adjustment speed: ASIC manufacturing takes months, while eWatts runs on commodity DRAM that billions of devices already have. eWatts free entry is closer to the theoretical ideal than any existing PoW network.

How the emission formula works

emission = clamp(100 x total_eff / hist_avg, 5, 2000)

total_eff is the sum of all miners' effective committed work in AOPS. hist_avg is the trailing average over 100 blocks (~16.7 hours). When network work equals its average, emission is exactly 100 eWatt per block. The short window means organic multi-year growth barely moves the ratio — the clamps exist for abrupt shocks, not trends. Effective issuance is near-constant at ~5.26M eWatts/year.

The first 10,000 blocks carry a ramp-up cap of 80% (no single miner receives more than 80% of the block reward; excess burned) and a founder lock of 50,000 blocks on early coinbase outputs.

What the protocol does not do

  • No price target. No $1.00/eWatt programmed value. The market discovers price; the protocol only measures energy.
  • No inflation target. No arbitrary rate codified. Absolute issuance is near-constant; percentage inflation declines naturally.
  • No supply cap. Hard caps create hoarding pressure. Scarcity here is physical production cost, not a number.
  • No halving schedule. No time-based decay. Emission responds to delivered work, not a calendar.
  • No oracles. No price feeds, no external dependencies, no governance committees.
  • No founder allocation. No pre-mine, no admin keys, no privileged minting.
  • No burn auction. Free entry is the auction. No mechanism needed beyond what exists.

Assumptions & considerations

  • Consensus constants from eWatts v0.5 (constants.rs, reward.rs, vr.rs, proof.rs), protocol version 0x0005.
  • Node uniformity: all simulated nodes commit ~20M AOPS at 75W (calibration point). Real networks are heterogeneous (2-3x dispersion).
  • Free-entry equilibrium: assumes N x c = 100 x P. Nodes are the marginal producer. More efficient nodes earn excess profits, attracting entry until marginal node breaks even.
  • Price discovery: the model requires a market price P. Before exchange listing, P is indeterminate and equilibrium does not apply. The computational VR (vr.rs) still functions.
  • Transaction fees: ignored. In maturity, fees dominate miner compensation. The identity shifts to N x c = (100 + avg_fees) x P, tightening the equilibrium.
  • Electricity price default $0.10/kWh approximates US industrial average.
  • Reference inflation rates: Bitcoin 0.83% (post-2024 halving), gold ~1.7% (World Gold Council, 25-year average), USD M2 ~6.5% (Federal Reserve long-run average).
  • Risk of error: this model is a faithful re-implementation of the consensus formulas, but it is not consensus code. No external audit has yet validated either.
