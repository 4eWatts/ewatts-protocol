A fair means of exchange.
Backed by energy, secured by memory.

eWatts is a digital currency designed to be fair by default. Fair to mine (any computer can do it). Fair to value (backed by the energy cost of production). Fair to transact (private from the start, not as an afterthought).

The name comes from Watt, the unit of power — because each coin is referenced to the energy cost of mining it. Not arbitrary. Physics-based.

Why it matters

A more honest store of energy

Gold but accessible

Gold works as money because it is expensive to produce. That cost sets a floor under its value. eWatts does the same with energy. Each coin requires real electricity to mine. No arbitrary supply. The difference: eWatts mining runs on standard memory, with no specialized hardware required. Gold requires geology.

Mining that can't be monopolized

Hash-based mining concentrates over time into specialized hardware (ASICs), making it impractical for general-purpose computers. eWatts uses memory bandwidth instead of hash power — every computer ships with DRAM, and the energy cost of accessing it is a physical constant. Mining cannot be monopolized by hardware that doesn't exist yet.

Value is grounded in energy cost

Miners cannot profitably sell below their energy cost. New miners enter when price exceeds it. Over time, the market oscillates around this energy floor — not as a peg, but as a physical boundary. The network's Value of Resource (kWh per coin) is visible on every block. There is no halving schedule because supply responds to actual bandwidth demand, not a fixed calendar.

Private from the start, not an option

Every transaction uses stealth addresses (recipient hidden), ring signatures (sender hidden), and Pedersen commitments (amount hidden). No selective disclosure. Not "public by default, private if you opt in." Privacy is the only mode.

Protocol

Architecture

eWatts is built around a simple idea: make mining accessible to anyone with a computer. The algorithm is designed to run fastest on standard RAM — not on specialized hardware. Transactions are private by default, and the network has no central authority, no admin keys, and no foundation.

Mining runs on standard RAM

No ASICs, no GPUs required. Mining speed is determined by how fast your computer can read its own memory. Every computer has RAM. Every computer can mine. The algorithm performs random memory accesses that scale with bandwidth, not clock speed.

Your identity is hidden

Each transaction is signed with a ring of 11 possible keys. An observer cannot tell which key produced the signature. The same key can be used multiple times without linking the transactions together.

Transaction amounts are hidden

The value of each transaction is encrypted inside a cryptographic commitment. Range proofs prove the amount is positive without revealing it. The total supply remains auditable by summing commitments on-chain.

Every payment gets a unique address

Each transaction creates a one-time destination known only to the recipient. No two payments to the same person can be linked. Only the recipient can prove they received it.

Money supply follows energy cost

New coins are emitted proportionally to total network bandwidth. More miners means more emission, but each coin costs energy to mine. The ratio (kWh per coin) is visible on every block. No fixed halving schedule. Just physics.

No one controls the network

No developer fund. No admin keys. No foundation. No CEO. Protocol changes require 95% of miners and 95% of nodes. The rules are enforced by code, not by people.

Get started

Mine in 5 minutes

You need a computer with Rust installed. Minimum 4 GB of free DRAM. No GPU, no ASIC, no token purchase.

# Install Rust
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Clone
$ git clone https://github.com/4Ewatts/ewatts-protocol.git
$ cd ewatts-protocol
$ cargo build --release

# Initialize state and mine
$ ./target/release/ewatts-protocol init
$ ./target/release/ewatts-protocol mine

# Start dashboard on port 8080
$ ./target/release/ewatts-protocol dash
