It's the only cryptocurrency whose value both parties to a transaction can independently arbitrage against their local energy costs. Not arbitrary. Physics-based.

Why it matters

A more honest store of energy

A neutral settlement layer

eWatts is designed for cross-border trade and global collaboration: permissionless to use, private by default, and anchored to a real cost of production rather than to the policy of any country. Like gold, it has a production cost floor (energy). Unlike gold, it is perfectly divisible, transmissible at the speed of light, storable as a 32-byte key, and mineable on standard memory, leveraging computing infrastructure already in any country.

Why DRAM?

Most proof-of-work currencies use hash functions (SHA-256, Ethash) that improve ~25-30% per year with each new ASIC generation. eWatts uses random access to DRAM, a bottleneck that has not improved in 20 years.

The result: eWatts' energy anchor drifts ~1-2% per year; Bitcoin's drifts ~25-30%. The difference is structural and permanent. DRAM latency is bounded by the speed of light in silicon; no ASIC can shortcut it.

Money that works for credit, not against it

Most transactions are credit, not cash. Credit requires trust that a unit's value will hold through the loan term. Bitcoin's deflation disincentivizes lending; fiat inflation erodes loan value. Many countries have shown the cost when that trust breaks. eWatts offers a third path: an energy anchor drifting ~1-2%/year keeps the real value of a loan roughly stable. Emission is elastic (proportional to bandwidth, not a calendar). No central bank can print, devalue, or interfere. For countries facing monetary crisis, it provides a neutral standard that neither party controls.

Private by default, by design

Every transaction protects sender (ring signatures), recipient (stealth addresses), and amount (Pedersen commitments). Privacy is the only mode. Changing it requires 95% of miners and 95% of nodes, near-unanimous consent enforced by code.

Protocol

Architecture

eWatts is built around a simple idea: make mining accessible to anyone with a computer. The algorithm is designed to run fastest on standard RAM, not on specialized hardware. Transactions are private by default, and the network has no central authority, no admin keys, and no foundation.

Mining runs on standard RAM

No ASICs, no GPUs required. Mining speed is determined by how fast your computer can read its own memory. Every computer has RAM. Every computer can mine. The algorithm performs random memory accesses that scale with bandwidth, not clock speed.

Your identity is protected

Each transaction is signed with a ring of 11 possible keys. An observer cannot tell which key produced the signature. The same key can be used multiple times without linking the transactions together.

Transaction amounts are private

The value of each transaction is committed cryptographically, visible only to the parties involved. Range proofs prove the amount is positive without revealing it. The total supply remains auditable by summing commitments on-chain.

Every payment gets a unique address

Each transaction creates a one-time destination known only to the recipient. No two payments to the same person can be linked. Only the recipient can prove they received it.

Money supply follows energy cost

New coins are emitted proportionally to total network bandwidth. More miners means more emission, but each coin costs energy to mine. The emission formula anchors each eWatt to the energy cost of production, a universal physical unit not tied to any dollar peg. Full block validation is heavier than a single signature check. Each eWatt divides into 100 ecents (eWatt-cents). No satoshis. No mental math.

Governance designed for stability

Zero pre-mine. Zero founder allocation. No developer fund. No admin keys. No foundation. No CEO. No token sale. Mining starts at block 1 with all early coinbase outputs time-locked on-chain.

The protocol launches with intentionally minimal governance, the same model Bitcoin used in its early years. Major changes require 95% of miners and 95% of nodes. As the community grows, governance evolves from founder-led to technical maintainers to community stewardship. This is documented in the project's governance manifesto.

Roadmap

Phases

eWatts is in active development. These are the planned phases toward a self-sustaining network.

Phase 1 — Foundation

NOW

Protocol implementation in Rust, MBPoW mining, privacy layer (stealth addresses, ring signatures, Pedersen commitments). Local testnet. Full code audit and formal verification of critical paths.

Phase 2 — Testnet

Public testnet with incentivized mining. Community of Rust contributors forming around the codebase. Mining pool support. Basic wallet and exchange integration. Governance discussion begins with early contributors.

Phase 3 — Mainnet

Mainnet launch. Decentralized governance via lazy consensus and technical maintainers. Security audit results published. Reference wallet with GUI. DEX and CEX listings.

Phase 4 — Maturity

Community-driven governance with constitutional framework. Academic papers published. Cross-chain bridges. Hardware wallet support. Focus on adoption in trade finance and remittance corridors.

Get started

Mine in 5 minutes

You need a computer with Rust installed. Minimum 4 GB of free DRAM. No GPU, no ASIC, no token purchase.

# Install Rust
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Clone
$ git clone https://github.com/4Ewatts/ewatts-protocol.git
$ cd ewatts-protocol
$ cargo build --release

# Initialize state and mine
$ ./target/release/ewatts-protocol init
$ ./target/release/ewatts-protocol mine

# Start dashboard on port 8080
$ ./target/release/ewatts-protocol dash
