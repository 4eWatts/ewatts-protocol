Energy-backed neutral settlement layer
PoW with stable memory. Private. Fair.

There are roughly four ways to store and move value today. Fiat works but supply can expand silently. Gold has real cost but is slow and expensive to hold. Bitcoin is portable but supply doesn't expand with the economy and transactions are public.

eWatts bridges concepts from all three without replacing any. Supply expands at energy cost, like gold. It is divisible and decentralized, like Bitcoin. But mining uses DRAM, a technology that has been physically flat for 20 years (1-2%/year improvement vs 20-30% for ASICs). No ASIC can shortcut it. A computer from five years ago mines at the same efficiency as one built today.

Dual-layer design: mining is slow and DRAM-bound, creating coins at measurable energy cost. Transactions are fast and private (<3ms per signature). Sender, receiver, and amount are hidden by default.

No pre-mine. No token sale. No founder allocation. No company. Mining is the only way to acquire coins.

Why this matters

Neutral infrastructure for a connected world

A settlement layer with a physical anchor

Energy cost has been the most stable price reference over the last decades. Not arbitrary, not fixed, but physically bounded. That is the anchor eWatts is built on. Supply expands at energy cost, proportional to real activity, not political calendars. For cross-border trade, remittances, and privacy-preserving transactions, this combination of properties didn't exist before.

Private by default

Every transaction protects sender, recipient, and amount by default. Changing that requires 95% of miners and 95% of nodes. Privacy is the default mode, not an opt-in.

Protocol

Core design

Mining runs on standard RAM

No ASICs, no GPUs required. Any computer with RAM can mine — a machine from five years ago performs at the same efficiency as one built today. See the live testnet dashboard.

Private by default

Sender, recipient, and amount are hidden. Each transaction uses ring signatures (11 possible keys — an observer can't tell which is yours), one-time stealth addresses (no two payments to the same person can be linked), and Pedersen commitments that hide amounts while keeping total supply auditable.

Money supply follows energy cost

New coins are emitted proportionally to total network bandwidth. More miners means more emission, but each coin costs energy to mine. The emission formula anchors each eWatt to the energy cost of production, a universal physical unit.

Governance designed for stability

Major changes require 95% of miners and 95% of nodes. Governance evolves from founder-led to technical maintainers to community stewardship as the network grows.

Get started

Mine in 5 minutes

You need a computer with Rust installed. Minimum 4 GB of free DRAM. No GPU, no ASIC, no token purchase.

Quick install: curl -sSf https://ewatts.org/install.sh | bash

# Install Rust
$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Clone
$ git clone https://github.com/4Ewatts/ewatts-protocol.git
$ cd ewatts-protocol
$ cargo build --release

# Initialize state and mine
$ ./target/release/ewatts-protocol init
$ ./target/release/ewatts-protocol mine

# Start dashboard on port 8080
$ ./target/release/ewatts-protocol dash
