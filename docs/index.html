Grok: what AI thought

There are roughly four ways to store and move value today. Fiat is anchored on volatile government policies while supply expands silently devaluing principal. Gold has perceived real value but is slow and expensive to transact. Bitcoin is portable but deflationary and transactions are public.

eWatts bridges concepts from all three without replacing any. Supply expands at energy cost, like gold. It is divisible and decentralized, like Bitcoin. But mining uses DRAM, a technology that has been physically flat for 20 years (1-2%/year improvement vs 20-30% for ASICs). No ASIC can shortcut it. A computer from five years ago mines at the same efficiency as one built today.

Dual-layer design: mining is slow and DRAM-bound, creating coins at measurable energy cost. Transactions are fast and private (<3ms per signature). Sender, receiver, and amount are hidden by default.

No pre-mine. No token sale. No founder allocation. No company. Mining is the only way to initially acquire coins.

Protocol

Core design

Mining runs on standard RAM

No ASICs, no GPUs required. Any computer with RAM can mine — a machine from five years ago performs at the same efficiency as one built today. Explore the economic model.

Private by default

Sender, recipient, and amount are hidden. Each transaction uses ring signatures (11 possible keys — an observer can't tell which is yours), one-time stealth addresses (no two payments to the same person can be linked), and Pedersen commitments that hide amounts while keeping total supply auditable.

Money supply follows energy cost

New coins are emitted proportionally to total network bandwidth. More miners means more emission, but each coin costs energy to mine. The emission formula anchors each eWatt to the energy cost of production, a universal physical unit.

Governance designed for stability

Major changes require 95% of miners and 95% of nodes. Governance evolves from founder-led to technical maintainers to community stewardship as the network grows.

Get started

Mine in 5 minutes (Windows, Mac, Linux)

Any computer with 4 GB of RAM can mine. No GPU, no ASIC, no token purchase. Just RAM.

⚠️ Disk space: Compilation uses ~1.5 GB temporarily. Blockchain data is <50 MB.

🐚 Windows (PowerShell)

Open PowerShell. Paste commands ONE AT A TIME:

# Step 1 — Install Rust (~1 min)
PS> curl.exe --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# CLOSE and REOPEN PowerShell
# Step 2 — Download and compile (~6 min)
PS> git clone https://github.com/4Ewatts/ewatts-protocol.git
PS> cd ewatts-protocol
PS> cargo build --release

# Step 3 — Connect to testnet and mine
PS> .\target\release\ewatts-protocol start --p2p --p2p-port 9001 --dash-port 8080 --difficulty 1 --bootstrap /ip4/178.104.193.50/tcp/25080/p2p/12D3KooWDTpEvdP2FneHTxRSAhLLykRm5yRMff7S9v3Pvtz2RUf1

# Open http://localhost:8080 in your browser

Troubleshooting:
• Port in use: change --dash-port 8080 to --dash-port 8081
• Antivirus blocking: add target\release\ folder as exception
• Disk full: run cargo clean to free ~1.5 GB
• Git not found: install from git-scm.com (Windows) or apt install git (Linux)
