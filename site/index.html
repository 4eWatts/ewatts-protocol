Why Ewatts?

Every cryptocurrency today is either mineable by ASICs (unfair) or securable by staking (unfair). Ewatts is memory-bound — DRAM bandwidth is the most commoditized resource on Earth. Every computer has it. No one can monopolize it.

🧠

Memory-Bound PoW

Mining bottleneck is DRAM bandwidth, not computational power. DDR5, HBM, GDDR — all compete fairly. ASICs have no advantage.

🤫

Private by Default

Stealth addresses, ring signatures (MLSAG), Pedersen commitments, and range proofs. Origin, destination, and amount are hidden from everyone except the parties involved.

⚡

Fast Confirmations

Dual-hash architecture: slow mining blocks (600s) for security, fast transaction hash (<3ms) for ring signature verification. Pre-confirmations between blocks.

🔗

No Governance

No dev fund. No admin keys. No voting. Protocol changes require 95% miner + 95% node consensus via hard fork. The code is the law.

📈

VR-Backed Supply

Each Ewatt's value is referenced to the energy cost of mining it (Value of Resource). Emission adjusts to total network DRAM — no arbitrary halvings.

🌐

Permissionless P2P

libp2p-based gossip network. Any node can mine, relay, and validate. No permission needed. No minimum stake. Just DRAM.
