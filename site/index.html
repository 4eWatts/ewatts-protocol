Protocol

How Ewatts works

Ewatts is a single-chain, dual-hash protocol. Mining blocks require memory-bound proof of work (DRAM bandwidth, ~600s/block). Between blocks, a fast transaction hash verifies ring signatures in under 3 milliseconds.

Memory-Bound PoW

Mining is bottlenecked by DRAM bandwidth, not computation. DDR5, HBM, GDDR — all compete on equal footing.

Privacy by Default

Stealth addresses, MLSAG ring signatures, and Pedersen commitments. Sender, recipient, and amount are hidden from the network.

Value of Resource

Each block's emission is proportional to total network DRAM. No fixed schedule, no halving — just physics. VR = kWh per Ewatt.

Immutable Core

No dev fund. No admin keys. No governance. Protocol changes require 95% miner + 95% node consensus via hard fork.

Get Started

Mine Ewatts in 5 minutes

You need a computer with Rust and at least 4 GB of RAM. No GPU required. No ASIC. Just memory.

# Install Rust (if you don't have it)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Clone and build
git clone https://github.com/4Ewatts/ewatts-protocol.git
cd ewatts-protocol
cargo build --release

# Initialize and mine
./target/release/ewatts-protocol init
./target/release/ewatts-protocol mine

# Start the dashboard
./target/release/ewatts-protocol dash
